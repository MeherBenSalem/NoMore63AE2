# Art tools

Every texture in `common/src/main/resources/assets/corerpg_quests/` is generated by these scripts, so the art is
original and can be rebuilt or tweaked in one place.

| Script | Writes |
|---|---|
| `generate_textures.py` | Item textures and models (`quest_book`, `smart_filter`, `loot_crate`, `missing_item`), quest node shapes and their 4px outlines (`textures/gui/shape/`, 64x64 white masks the quest book tints), GUI icons (`textures/gui/icon/`, 16x16 white glyphs for tinting) and the mod icon (`icon.png`, 256x256). |
| `write_empty_structure.py` | `data/corerpg_quests/structure/empty.nbt`, the all-air 5x5x5 GameTest template (DataVersion 3955, Minecraft 1.21.1). It reads the file back to check it. |

```bash
python3 tools/art/generate_textures.py      # needs Pillow
python3 tools/art/write_empty_structure.py  # no dependencies
```

Pixel art (items, icons) is defined as character maps at the top of `generate_textures.py`; shapes and the mod
icon are drawn at 4x and downsampled for clean edges.
