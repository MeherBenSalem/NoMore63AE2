# Core RPG - Quests Engine 1.0.2

## New Minecraft versions

The mod now runs on more Minecraft versions and loaders. Pick the jar that matches **both** your Minecraft version and
your loader:

* **Minecraft 1.20.1** on **Fabric** and **Forge** (new)
* **Minecraft 1.21.1** on **Fabric** and **NeoForge**
* **Minecraft 26.2** on **Fabric** and **NeoForge** (new)
* **Minecraft 26.3** on **Fabric** and **NeoForge** (new)

Every version has the same quest book, editor, teams, filters and vein mining, with these differences:

* **1.20.1:** items carry NBT instead of data components. Item filters' `component(...)` checks the matching NBT (for
  example `component(minecraft:custom_name)` checks the custom name), and items saved in a quest book with 1.21-style
  components load without that extra data.
* **26.2 and 26.3:** locked quests show their item icons untinted, and long button labels are cut off instead of
  scrolling.
* **26.3:** the right-click area tools (strip, path, till) recognise axes, shovels and hoes by their item tags, so
  modded tools in those tags work too.

Jar names changed to `corerpg_quests-<loader>-<minecraft>-1.0.2.jar`.
