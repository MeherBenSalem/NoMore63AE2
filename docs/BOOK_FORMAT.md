# Quest book file format

_Generated by `tools/gen_book_docs.py` from the mod's source. Do not edit by hand._

The quest book lives in `config/corerpg_quests/book/`:

```
book/book.json                 book settings, chapter groups, chapter order
book/chapters/<id>.json        one chapter: its settings, quests, links and images
book/reward_tables/<id>.json   one reward table
```

Every object has an `id` (lower case, 1-64 characters of `a-z 0-9 _ - . /`, unique in the whole book).
Only values that differ from the default are written. Text supports `&` colour codes and a `lang:` prefix for
translation keys. Items are an id (`"minecraft:diamond"`) or the vanilla item stack object
(`{"id": ..., "count": ..., "components": {...}}`). Icons are an item or `{"texture": "ns:path.png"}`.
Tasks and rewards have a `type` (`item`, `kill`, ... or `namespace:path` for addon types).

## Common fields (every object)

| Key | Type | Default | Meaning |
|---|---|---|---|
| `title` | text | `` | The name shown in the quest book. Leave empty to use a sensible default. Supports & colour codes. |
| `icon` | icon | — | An item or texture shown as the icon. Leave empty to use the first task's icon. |
| `tags` | list of text | — | Free-form labels for searching and for scripts. |

### Chapter

A chapter file also holds `quests`, `links` and `images` arrays.

| Key | Type | Default | Meaning |
|---|---|---|---|
| `subtitle` | text lines | — | A short line shown under the title. |
| `group` | id | — | The chapter group this chapter is listed under. |
| `default_quest_shape` | one of QuestShape | default | The outline drawn around quest icons. |
| `default_quest_size` | number | 0 (0 to 8) | How big quests are drawn, in grid units. |
| `default_min_width` | integer | 0 (0 to 3000) | Minimum width of the quest panel for quests in this chapter. |
| `default_hide_dependency_lines` | true/false | false | Hide the lines between quests in this chapter by default. |
| `always_invisible` | true/false | false | Hide the chapter from players (it can still hold linked quests). |
| `hide_quest_details_until_startable` | true/false | false | Players only see quest details once the quest unlocks. |
| `hide_quest_until_deps_complete` | true/false | false | Quests appear only once their dependencies are done. |
| `hide_quest_until_deps_visible` | true/false | false | Quests appear only once their dependencies can be seen. |
| `hide_text_until_complete` | true/false | false | Keep descriptions secret until the quest is done. |
| `progression_mode` | one of ProgressionMode | default | Linear: tasks count only after the dependencies are done. Flexible: tasks count any time. |
| `consume_items` | one of Tristate | default | Whether item tasks take the items. |
| `require_sequential_tasks` | one of Tristate | default | Tasks must be completed in the order they are listed. |
| `autofocus` | id | — | The quest the canvas centres on when the chapter opens. |

### Quest

A quest also holds `tasks` and `rewards` arrays.

| Key | Type | Default | Meaning |
|---|---|---|---|
| `subtitle` | text | `` | A short line shown under the title. |
| `description` | text lines | — | The quest text. Use & colour codes; a line with {@pagebreak} starts a new page. |
| `guide_page` | text | `` | A web page (wiki, docs) the quest links to. |
| `x` | number | 0 (-100000 to 100000) | Horizontal position, in grid units. |
| `y` | number | 0 (-100000 to 100000) | Vertical position, in grid units. |
| `shape` | one of QuestShape | default | The outline drawn around the icon. |
| `size` | number | 0 (0 to 8) | How big it is drawn, in grid units. 0 uses the chapter default. |
| `icon_scale` | number | 1 (0.1 to 4) | Scales the icon inside the shape. |
| `min_width` | integer | 0 (0 to 3000) | Minimum width of this quest's panel. |
| `dependencies` | list of ids | — | Quests (or whole chapters) that unlock this quest. |
| `dependency_mode` | one of DependencyMode | all_completed | Whether all or one of the dependencies must be completed or started. |
| `min_required_dependencies` | integer | 0 (0 to 1000) | Unlock once this many dependencies are complete (0 uses the dependency mode). |
| `max_completable_dependents` | integer | 0 (0 to 1000) | How many quests that depend on this one can be completed. Use 1 for an either/or choice. |
| `hide_dependency_lines` | one of Tristate | default | Hide the lines to this quest's dependencies. |
| `hide_dependent_lines` | true/false | false | Hide the lines to quests that depend on this one. |
| `invisible` | true/false | false | Hidden until completed. |
| `invisible_until_tasks` | integer | 0 (0 to 1000) | Hidden until this many of its tasks are done. |
| `hide_until_deps_complete` | one of Tristate | default | Hidden until its dependencies are done. |
| `hide_until_deps_visible` | one of Tristate | default | Hidden until its dependencies can be seen. |
| `hide_text_until_complete` | one of Tristate | default | Keep descriptions secret until the quest is done. |
| `hide_details_until_startable` | one of Tristate | default | Players see the details only once the quest unlocks. |
| `hide_lock_icon` | true/false | false | Do not draw the padlock on this quest while it is locked. |
| `optional` | true/false | false | Not needed to complete the chapter. |
| `repeatable` | true/false | false | Starts over once all its rewards are claimed. |
| `repeat_cooldown` | integer | 0 (min 0) | Seconds before a repeatable quest can be done again. |
| `progression_mode` | one of ProgressionMode | default | Linear: tasks count only after the dependencies are done. Flexible: tasks count any time. |
| `require_sequential_tasks` | one of Tristate | default | Tasks must be completed in the order they are listed. |
| `disable_completion_toast` | true/false | false | Do not show the 'Quest complete' toast. |
| `completion_command` | text | `` | A command the server runs when the quest completes. {p} is the player, {team} the team, {quest} the quest. |
| `ignore_reward_blocking` | true/false | false | Can be claimed even while an admin has blocked rewards. |
